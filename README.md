# GlobeTrek – Travel and Tour Management System

## Project Overview

GlobeTrek is a web-based travel and tour management system developed to manage travel packages, customer bookings, and travel-related inquiries.

## Key Features

- User registration and login
- Travel package browsing
- Package details management
- Customer booking management
- Custom trip requests
- Customer dashboard
- Staff management dashboard
- Admin dashboard
- Booking and inquiry management

## Technologies Used

| Category | Technologies |
|---|---|
| Frontend | HTML, CSS, JavaScript |
| Backend | PHP |
| Database | MySQL |
| Local Development | WAMP Server |
| Version Control | Git and GitHub |

## Project Structure

- `admin/` – Administrator features
- `assets/` – CSS, JavaScript and images
- `customer/` – Customer features
- `database/` – Database SQL file
- `includes/` – Shared PHP files
- `staff/` – Staff features

## Installation and Setup

1. Install and start WAMP Server.
2. Clone this repository.
3. Place the project inside the WAMP `www` directory.
4. Create a MySQL database named `globetrek`.
5. Import the SQL file from the `database/` folder.
6. Configure the database connection using `includes/db_connect.example.php` as a reference.
7. Open the project in your browser:

`http://localhost/globetrek/`
